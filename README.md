# Веб-шлюз open1 для открывалки ворот

Нужен для получения команд на открытие из приложения на андроиде. Можно обойтись и без него и открывать ворота в фирменном приложении умного дома, но мы же хотим автоматизации в виде: запустил приложение - ворота открылись, а не: запустил приложение - нашёл кнопку, нажал и ворота открылись. Итак, открывалка уже есть в списке устройств и вам нужно получить две вещи:

1. Токен для работы умным домом Яндекса: читаем вот эту статью https://habr.com/ru/articles/789200/ там всё просто, не забудьте только, что bearer токен выдается по умолчанию на год и когда срок выйдет, сработает условие из `update_yandex_iot_token()`, которое сохранит новый токен. Результат - сохраненный в файле `iot_yandex_token.json` ваш токен для умного дома. 
2. device id открывалки: из этой же статьи возьмите код и в нём метод `get_yandex_iot_info()`, который выведет все данные по всем устройствам вашего умного дома, нужный id увидите глазами

Все правки, которые нужно внести в одном месте:

* `iot_yandex_token.json` - тут ваш токен для умного дома
* `func.php` - тут ваши `$yandex_iot_client_id` и `$yandex_iot_client_secret` (вы их испльзовали для получения токена)
* `open-common.php` - поправить путь к логу, в который будет сохраняться каждый запрос к шлюзу (где `file_put_contents()`)
* `open1.php` - вносим свои `valid_tokens` с которыми будет авторизовываться андроид приложение и прописываем свой `device_id`. Токены приложения передаются в http-заголовке.

Скрипты размещаете на каком-нибудь хостинге, вам нужен рабочий url до open1 скрипта, типа `https://somedomain.ru/open1`
Далее - собираем андроид-приложение [тут](https://github.com/spiritkind/open1_app)
